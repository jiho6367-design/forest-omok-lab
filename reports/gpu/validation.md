# GPU 혼합 모드 검증

2026-10-02 배포 변경: GPU 패턴 사전 계산, 줄별 점수 재사용, GPU 모드 3종, 정확한 5목 우선 규칙 고정.

## 확인한 동작

- CPU 패턴 기준표로 80개 판과 양쪽 색의 36,000개 Forest 착수 검사 결과를 기존 경로와 비교했습니다. Reader 합법 수와 후보 순위도 동일했습니다. 깊이 3의 세 국면에서 점수·수순·노드 수가 동일했습니다. `npm run test:gpu`로 재현합니다.
- WebGPU 셰이더의 59,049개 결과 전수 검증을 Edge에서 통과했습니다. 초기 실측 어댑터는 Intel xe-3lpg였습니다. 이후 사용자가 고성능 GPU를 지정한 화면에서 `nvidia blackwell` 및 검증 완료를 확인했습니다. RTX 노트북의 어댑터 선택 변경은 사용자 제공 화면으로 확인한 것이며, 전체 GPU 활용률이나 GPU만의 탐색 속도를 측정한 것은 아닙니다.
- 최초 로컬 Edge 실측의 고정 깊이 작업은 기존 CPU 대비 약 1.30~1.33배였습니다. CPU 최적화도 거의 같은 속도였습니다. 사용자 제공 NVIDIA 실행 화면의 표시된 두 국면은 1.22~1.32배였고, 1초 분석에서 GPU 혼합의 완료 깊이는 4, 기존 CPU는 3이었습니다. 이를 모든 국면의 속도나 품질 보장으로 해석하지 않습니다.
- 정확한 5목·3×3·4×4·장목 등 규칙 조합과 Worker 종료·취소·결과 보존 검사를 실행했습니다.
- 세 프리셋의 시간 연결, 선택 저장, 재분석, 직접 시간 지정과 CPU/GPU 전환을 확인했습니다.

## 기존 전체 회귀 실패

이전 로컬 `npm test`는 `test/unified.cjs:96`의 ‘automatic analysis prevents the 74 E15 loss by recommending E11’ 항목에서 실제 추천 136과 기대 154가 불일치했습니다. 수정 전 GitHub main 소스에서도 같은 값을 재현했습니다. 따라서 이 GPU 변경에 대해 전체 회귀 통과를 주장하지 않습니다. 시간 제한 탐색의 추천 안정성은 별도 개선 과제로 남습니다. GPU 모드의 전수 규칙 비교와 동일 작업 검사를 이 실패의 대체로 해석하지 않습니다.

2026-10-02 공개 전 전체 검사도 같은 E11 추천 기대 항목에서 실패했습니다(실제 7, 기대 154). 원본의 해당 항목을 별도로 재실행했을 때는 실제 136, 기대 154로 실패했습니다. 실행 순서와 시간 제한에 따라 실패 결과가 달라지므로 특정 추천값의 재현 안정성을 주장하지 않습니다. GPU 패턴 전수 비교, 고정 깊이 동등성, Worker 생명주기, 기존 반증과 VCF 전처리 검사는 통과했습니다.

공개 전 추가 검증에서 historical, historical-progress, proof-certificate, root-screen 검사도 종료 코드 0으로 통과했습니다.

## v5.13.1 자동 검사 수정

위 실패 기록은 v5.13.0의 당시 결과입니다. GitHub Actions에서도 같은 고정 좌표 기대값 실패를 확인했습니다. 재검사에서 Reader가 E11 자체를 `forced-reply-trap` 수순으로 반증하는 경우가 있었고, 전체 합법 수의 패배를 증명하면 E15를 저항 수로 반환하는 경우도 있었습니다. 따라서 E11을 무조건 안전한 정답으로 강제하거나 패배 판정을 숨기는 수정은 하지 않습니다.

- 통합 엔진이 Reader의 `line` 형식 반증을 심층 후보 선택과 합법 대안 선택에서 유지하도록 수정했습니다. 높은 심층 평가점수가 이전의 반증을 무효화하지 않습니다.
- 심층 결과를 채택하지 않은 경로에서도 자동 분석 표시를 유지합니다.
- 기존 기보 검사는 판 보존, 합법 착수, 수순 유효성, 증거가 있는 E15 반증, 반증된 수의 미확정 추천 방지, 전체 패배가 증명된 경우의 패배 표시를 확인합니다. H11 회귀도 어느 엔진이 먼저 반증했는지에 무관하게 증거와 패배 판정을 확인합니다.
- 별도 제어 검사에서 Reader의 `line`, `pv`, `replyTrap`, 검증 캐시 반증을 모두 심층 결과보다 우선하도록 확인합니다. 증거 없는 미완료 검사는 후보를 배제하지 않습니다.
