# 공격 지속·방어·역공 및 25초 분석 변경

기준일: 2026-10-21. 버전 5.18.0, 전략·탐색 캐시 `initiative-2`.
AI-Lecture의 입력 확인, 제작, 기능 검증, 실전 평가 구분을 적용했다.
공개 README·가이드와 로컬 1~9강 요약을 참고했으며 영상·전체 강의 받아쓰기를 읽었다는 뜻은 아니다.

## 확인한 원인과 수정

1. Forest의 일반 탐색 깊이 끝에서 공격 연결 조건을 충족하지 않는 순수 방어 차단 수와 단일 4 공격이 탈락했다. 상대 응수와 자신의 다음 공격을 평가하기 전에 정적 평가로 돌아가는 분기였다. 이제 공격 대표와 방어 차단 대표를 각각 유지하고, 폭 2·연장 2수의 제한 안에서 실제 응수를 읽는다. 색에 고정된 공격·방어 성향을 넣지 않았다.
2. 종전 심층은 일반 후보 비교를 `min(15초, 요청의 60%)`로 제한하고 이후 상위 후보만 검사했다. 이제 심층은 비교에 82%를 배정하며 Forest의 후보 32개·분기 18개·최대 깊이 12 프로필을 사용한다. 넓어진 탐색과 연장 때문에 표시되는 완료 깊이가 이전보다 작을 수도 있다. 깊이 숫자만으로 효과를 판단하지 않는다.
3. 브라우저의 한 Worker에서 일반 비교를 실행하던 경로에 후보 분할을 추가했다. 하드웨어 동시 실행 수가 6 이상이면 자동·심층은 후보 Worker 3개와 기존 증명 Worker를 사용한다. 동일 깊이의 후보 비교가 모두 끝난 결과만 게시한다. 자동은 24개, 심층은 32개 후보를 비교한다. 직렬 증명에서 새로 반증한 수는 병렬 결과와 시간 초과 대안에서도 제외한다.
4. 병렬 결과 자체의 마지막 응수 검사도 예약했다. 후보 비교를 먼저 끝내고 실제 상위 후보 최대 3개를 새 Worker에서 최대 1.2초 검사한다. 완료 전 중단된 검사는 안전·필승 증거가 아니다. 발견한 반증은 검사 중 즉시 보존한다. 계산 도중 설정을 바꾸면 증명·후보·검사 Worker를 모두 종료한다.

즉시 승리, 필수 방어와 기존 정확한 5목·양측 3·3 금수·장목 규칙은 유지한다. 과거 국면의 패배가 새 국면의 승리·역공을 가리지 않는지 검사한다. 강제패배에서도 합법적인 저항 수를 표시한다.

## 시간·속도와 표시

| 모드 | 요청 최대 | 동작 |
|---|---:|---|
| 빠르게 | 1초 | 짧은 후보 비교 |
| 자동 | 15초 | 국면별 예산, 완료된 비교가 안정되면 조기 종료 |
| 심층 | **25초** | 후보 확장·반복 심화·최종 응수 검사 |

최종 지시는 30초안에서 **25초 상한**으로 변경됐다. 40초 대국 시계에서는 남은 시간에서 3초를 남긴다. 내부 여유와 Worker 종료용 감시 타이머를 두고, 상한에서 마지막 완료 비교를 반환한다. 완료 비교가 없으면 미검증 합법 후보임을 표시한다. 브라우저/운영체제 스케줄러 정지까지 포함하는 실시간 시스템 보장은 아니며, 실제 Edge 검사와 가상 시계의 상한·늦은 메시지 검사를 함께 수행했다.

화면에 선택·적용 예산, 실제 시간, 완료 깊이와 미완료 사유를 표시한다. 탐색 점수를 승률 백분율로 바꾸지 않는다. `analyze`는 기존 숫자·`auto`와 새 `{mode, ms, automatic}`을 받는다. 기존 선택·수동 시간 저장 형식은 유지한다.

이 장비는 논리 CPU 16개와 RTX 5070 Laptop을 사용한다. 수읽기의 가지 분기는 CPU에서 처리하고 GPU는 기존 패턴 계산과 CUDA 신경망 학습에 사용한다. 이번 변경은 GPU 사용률을 억지로 높이는 작업이 아니다. 같은 후보·깊이·모델에서 실제 소요 시간과 탐색 결과를 비교했다.

학습 초기화는 해당 cycle의 optimizer 체크포인트 재개, 현재 학습 후보, 가져온 warm-start, 기존 champion 순이다. 가져온 warm-start보다 champion을 먼저 선택하던 우선순위를 수정하고 생성 fixture로 실제 trainer 인수와 champion 보존을 검사했다. 병렬 학습 검사도 명시적 fixture 모델로 격리하여 로컬 운영 모델의 대용량 노출 원장에 의존하지 않게 했다.
