## 비용이 발생한 경로와 수정

`src/reader-engine.js`는 첫 정적 평가에서 신경망 accumulator를 생성한다. 기존에는 생성된 뒤 모든 `set()` 착수와 되감기에서 `neuralPosition.set()`을 호출했다. 전술 증명·후보 점검이 여러 가상 분기를 방문한 뒤 같은 보드로 복귀해도 그 중간 상태를 모두 신경망 특징으로 계산했다. 모델 점수가 필요하지 않은 구간의 비용도 제한 시간에 포함됐다.

수정은 변경된 좌표를 한 번씩 표시하고 다음 정적 평가 직전에 **현재 보드의 최종 값**으로 동기화한다. accumulator 생성 이전에는 변경 목록을 쌓지 않는다. 반복 착수·되감기로 상쇄되는 상태를 계산하지 않으며, 모델을 끈 경로에는 신경망 목록을 할당하지 않는다. 모델 가중치·특징 정의·후보 순위·전술 증명·규칙은 유지한다.

개발 자료에서 국면 선택 규칙을 먼저 저장했다. cycle 3의 train-terminal 자료에서 돌 수 구간 `[2,8]`, `[9,16]`, `[17,24]`, `[25,40]`마다 파일 순서상 처음 두 개의 서로 다른 가족을 선택했다. 라벨·대국 결과·final-test를 보고 선택하지 않았다. 보존 checkpoint에서 trial 70 모델을 복원하고 객체 hash와 model ID를 확인했다.

## 남은 학습 병목

teacher 경로의 유효 기여가 거의 없는 것도 확인했다. trial 70 prepared train의 83,383행 중 terminal 83,349행, teacher 34행이었다. teacher 행 비율은 0.0408%지만 confidence와 가족 균형 가중치까지 적용한 실제 가중치 비율은 약 **0.0000112%**였다. validation 8,305행은 전부 terminal이다.

현재 teacher 분석은 기존 기보를 대상으로 하고 신규 self-play 위치에는 teacher를 추가하지 않는다. 분석 완료 위치를 재사용하며, `tanh(score/200000)`으로 34행 중 31행의 목표 절댓값이 0.01 미만이다. 따라서 더 긴 탐색의 평가값을 배우는 통로가 매우 약하다. 미채택 후보는 다음 모델 초기값으로 이어받지만 self-play는 채택된 champion만 사용한다.

관점 반전·warm-start 정규화·모델 선택의 명백한 오류는 찾지 못했다. terminal 회귀가 틀렸거나 위 teacher 병목이 단독 원인이라고 단정하지 않는다. 후속 개선은 train/development의 서로 다른 가족에서 teacher coverage를 확보하고 terminal-only와 혼합 목표를 같은 초기값·seed·자원으로 비교한 뒤 새 독립 대국 평가를 계획하는 것이 적절하다. 이번 수정에는 검증되지 않은 teacher 증폭이나 순위 변경을 넣지 않았다.
