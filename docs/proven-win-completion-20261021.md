# 강제승 증명 즉시 확정 — v5.18.1

사용자의 최종 요청에 따라 **내 강제승이 증명된 경우에만** 다른 후보 비교를 중단하고 추천을 확정한다. 패배 직전의 방어·저항·역공 분석 시간이나 기존 강제패배 판정 조건은 바꾸지 않았다. 빠르게 1초·자동 최대 15초·심층 최대 25초 상한도 유지한다.

## 확인한 원인과 변경

1. `src/parallel-analysis.js`의 700ms 준비 탐색은 Reader의 강제승 증명을 찾으면 후보 비교용 `rootFrontier`를 만들지 않고 반환한다. 기존 수신 경로는 이를 후보가 없는 준비 실패로 처리해 그 승리 증명을 버렸다. 이제 Reader의 실제 `win`/`forced` 증명을 전달하고 나머지 Worker를 종료한다.
2. `src/unified-app.js`는 진행 메시지의 `proven:true`도 임시 추천으로만 표시했다. 이제 기존 증거·합법성·PV 검사를 통과한 내 승리 진행 결과를 즉시 최종 추천으로 처리하고, 직렬·병렬 Worker와 타이머를 정리한다. 이후 늦게 도착한 메시지는 결과를 바꾸지 못한다.

기존 **최종** 승리 메시지는 이미 병렬 비교보다 우선했다. 이번 변경은 버리거나 임시로 남기던 증명 전달 경로를 보완한다. 높은 평가점수·불완전한 탐색·개별 후보의 패배를 승리 증명으로 바꾸지 않는다. 별도의 긴 quiet 탐색이나 새 신경망 학습은 추가하지 않았다. Reader·Forest·통합 Node 엔진·규칙·모델·학습 실행기 소스는 동일하다.

최근 사용자가 관찰한 실제 대국 기보는 확보하지 못했다. 다음 결과는 생성 국면과 실제 브라우저 전달 경로의 재현이며, 해당 대국의 지연 원인을 그대로 재현했다는 주장이 아니다.

## 검증

- `node test/proven-win-latency.cjs`: 두 생성 전술, 흑백 교환, 회전·반사에서 자동·심층 64개 강제승 검사. 별도 Forest 규칙 구현으로 합법 상대 응수 31,296개를 재생했다. 다단계 공격·입력 복원·즉시 반격승·3·3 금수·장목·중단된 증명을 검사했다. 시간 합격 조건은 논리 시계이며 실측 시간으로 기력이나 보편적인 지연 상한을 주장하지 않는다.
- `node test/worker-lifecycle.cjs`: 승리 진행 결과의 즉시 완료, Worker·타이머 정리, 늦은 메시지 차단. 패배 진행 메시지·큰 평가점수·증거 검사에서 취소된 증명은 이번 즉시 완료 조건에 들어가지 않는다.
- `node test/parallel-analysis.cjs`: 실제 Reader의 강제승 준비 결과를 자동·심층에서 전달한다. 기존 동일 깊이 비교·후보 반증·최종 검사·시간 종료 검사도 통과했다.
- `npm run test:analysis:ui`: 실제 Edge 및 네이티브 Worker 검사 통과. 생성 합법 대국에서 일반 메시지, 직렬 최종 증명을 진행 메시지로 전달하는 제어 조건, 직렬 메시지를 보류하고 병렬 준비 증명만 받는 제어 조건을 흑백·모드별 16개 검사로 구분했다. 모든 경우 화면은 `분석 완료 · 강제승`, 활성 Worker는 0개였다. 마지막 실행에서 단순 국면의 일반 전달은 약 35~168ms였으며, 일반 국면의 속도 보장은 아니다.
- 수정 전 두 전달 함수로 구성한 비교 HTML은 일반 최종 메시지 조건에서는 통과했지만, 실제 승리 증명을 진행 메시지로 전달하는 조건에서는 7초 내 완료하지 못했다. 수정 후 같은 조건을 통과했다. 이는 전달 경로 재현이고 사용자 원본 대국 재현이 아니다.
- 기존 일반 국면의 자동 24후보·심층 32후보 비교, 심층 25초 상한, 후보 최종 검사와 Worker 정리도 통과했다.
- `npm run test:search-budget`, `node test/reader-loss-contract.cjs`, `node test/turn-memory-worker.cjs`, `node test/recommendation-policy.cjs`, `node test/build-model.cjs` 통과. 기존 패배 증거·저항 후보 계약은 유지한다.

실제 Edge는 샌드박스 안에서 시작 시 종료되어, 허용된 일반 실행 환경에서 검증했다. 검사 상세·화면·수정 전 비교물은 비공개 로컬 `work/proven-win-20261021/`에 둔다. 전체 장기대국 평가를 새로 실행한 것은 아니다.
