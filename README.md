# 숲속 오목 연구실

초록 슬라임과 노란 버섯 돌로 즐기는 로컬 실행형 오목 분석 도구입니다. 설치나 서버 없이 `outputs/omok.html` 파일을 브라우저로 열면 바로 실행됩니다.

## 실행

1. 이 저장소를 내려받습니다.
2. `outputs/omok.html`을 더블 클릭해 브라우저에서 엽니다.

## 포함 기능

- 15×15 오목판, 5개 화점 표시, 슬라임·버섯 돌 선택
- 선공/후공 및 돌 선택, 40초 턴 타이머와 패스 처리
- 3×3 금수 판정, 정확히 5목 승리 및 6목 비승리 규칙
- 위협 우선 탐색, 즉시 4목 방어, 상대 예상수와 다음 추천수 제시
- 착수 기록, 텍스트 복사, 복기 및 방어 점검

게임 규칙과 분석 결과는 로컬 브라우저에서 처리됩니다.
