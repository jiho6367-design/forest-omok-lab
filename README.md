# 오목 수읽기

인터넷 연결 없이 브라우저에서 실행하는 15×15 오목 수읽기 도구입니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge로 엽니다.

## 규칙

- 정확히 5목이 승리입니다.
- 6목 이상은 착수할 수 있지만 승리로 계산하지 않습니다.
- 양쪽 모두 열린 3을 두 방향 이상 동시에 만드는 3·3은 금지합니다.
- 4·4는 허용합니다.

## 개발

```powershell
node build.cjs
node test.cjs
```

테스트는 기보 복기, 금수, 필수 방어, 연속 위협, 자동 수읽기 및 추천 유효성을 검사합니다.
